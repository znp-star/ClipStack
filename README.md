# ClipStack

Windows 11 的本地剪贴板管理器。交互以 **Win+V** 为骨架，补上内置版本缺的搜索、置顶、编辑、类型过滤、可调保留期与可配置快捷键。

只用本地存储，不做云同步；敏感内容只留在内存里，永远不落盘。

> 状态：核心功能与发布链路已完成（M1–M6）——剪贴板监听、SQLite 入库、回贴（还原前台窗口后发粘贴）、面板视觉与尺寸记忆、图片捕获、置顶 / 编辑 / 类型过滤、敏感内容、托盘与开机自启、定时清理、设置与可配置快捷键、Velopack 打包与自动更新。设计细节见 [PLAN.md](PLAN.md)。

## 特性

**已实现**

- Win+V 式面板：全局快捷键唤出、鼠标滚轮浏览、`↑` / `↓` 或点击选择、`Enter` 粘贴、`Esc` 关闭
- 粘贴时自动隐藏面板、还原原来的前台窗口再发送按键；终端类窗口改用 `Shift+Insert`
- 文本、图片、文件三类内容都能记录；图片转 PNG 落盘并显示缩略图
- 复制图片文件（非像素）时同样显示缩略图，粘贴回写为文件而不是路径文本
- 顶部过滤条：全部 / 文本 / 链接 / 图片 / 文件 / 敏感，`Ctrl+Tab` 循环切换；「链接」指整条内容就是一个网址（`http(s)://` 或 `www.` 开头），夹在文字里的网址仍算文本
- 置顶：`Ctrl+P` 切换，置顶区排在时间流上方并用一条细线分隔，不受保留期清理
- 编辑：`F2` 打开纯文本编辑窗口（`Ctrl+Enter` 保存），`Delete` 删除选中条目
- 敏感内容：密码管理器一类窗口来的内容只存在内存里，默认 10 分钟（可调 1–60），带「未保存」角标、不能置顶，应用退出即清空
- 条目预览浮层：悬停或用 `↑` / `↓` 选中条目时，图片展开成大图、超过两行的文本展开全文；可在设置里关掉
- 无边框面板 + DWM Mica 背景，四边可拖拽缩放，位置尺寸按显示器记忆
- 常驻通知区：左键唤出面板，右键菜单可暂停/恢复监听、切换主题、清空历史、设置、退出；Explorer 重启后图标自动恢复
- 开机自启（写 `HKCU\...\Run`，带 `--silent`，可在设置里关掉）
- 设置窗口：保留天数、敏感内容保留分钟、开机自启、主题三态（跟随系统 / 浅色 / 深色）、预览浮层开关、9 个动作可改的快捷键（带冲突提示，改完即时生效）
- 同一内容重复复制不新建条目，只把「最近使用时间」和次数往前推
- SQLite（WAL）存储，启动时 / 每小时 / 退出前按保留天数清理，置顶条目免疫，过期判断只看最近使用时间

## 系统要求

- Windows 11（Mica 背景需要 22621+，低版本自动回退为不透明背景）
- .NET 9 SDK（自行构建时）

## 构建与运行

```powershell
dotnet build ClipStack.sln
dotnet run --project src/ClipStack.App
```

`--silent` 参数启动时不显示面板，供开机自启使用；`--settings` 直接打开设置窗口（面板需要可见，因此与 `--silent` 同用时忽略）。

## 打包与发布

安装包与更新包由 [Velopack](https://velopack.io) 生成。先装一次 CLI：

```powershell
dotnet tool install --global vpk
```

再给定版本号打包（自包含 win-x64，目标机器不需要装 .NET 运行时）：

```powershell
./scripts/pack.ps1 -Version 0.1.0
```

产物在 `artifacts/releases`：

| 文件 | 用途 |
|---|---|
| `ClipStack-win-Setup.exe` | 安装包，装完即接入自动更新 |
| `ClipStack-win-Portable.zip` | 免安装版，不会自动更新 |
| `ClipStack-<版本>-full.nupkg`、`RELEASES` | 更新用的包与清单，由客户端拉取 |

发布：推一个 `v0.1.0` 形式的标签，GitHub Actions 会跑测试、打包并创建 Release；也可以在 Actions 页面手动触发并填版本号。客户端只在“由安装包装出来的”副本上检查更新，`bin\` 里直接跑的开发版会提示无法自更新。


## 数据位置

全部数据都在 `%LOCALAPPDATA%\ClipStack\`：

| 路径 | 内容 |
|---|---|
| `clipstack.db` | SQLite 数据库（条目、来源、时间戳） |
| `settings.json` | 保留天数、敏感保留时间、主题、自启、预览开关、快捷键、面板几何 |
| `images\` | 图片条目，按内容哈希命名 |
| `logs\` | 每日日志，保留 7 天 |

日志只记哈希前缀与内容长度，不记剪贴板正文。

## 已知限制

- 只支持 Windows，只在 Windows 11 x64 上验证
- 回写图片同时放 `PNG` 和 `CF_DIB` 两种格式：浏览器 / Electron 程序只从 DIB 合成粘贴文件，只认 PNG 的目标仍能用 PNG。DIB 为 32 位 BI_RGB，透明度不保证保留（PNG 格式仍在，供支持的目标使用）。
- 权限提升的窗口、mstsc 远程桌面里只能复制，不能自动粘贴
- WSL 里只支持文本复制；图片复制需要经 Windows 侧工具
