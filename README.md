# ClipStack

Windows 11 的本地剪贴板管理器。交互以 **Win+V** 为骨架，补上内置版本缺的搜索、置顶、编辑、类型过滤、可调保留期与可配置快捷键。

只用本地存储，不做云同步；敏感内容只留在内存里，永远不落盘。

> 状态：**开发中**。已完成剪贴板监听、SQLite 入库、回贴（还原前台窗口后发粘贴）、面板视觉与尺寸记忆、图片捕获；置顶 / 编辑 / 类型过滤 / 设置界面 / 打包自动更新尚在开发。设计细节见 [PLAN.md](PLAN.md)。

## 特性

**已实现**

- Win+V 式面板：全局快捷键唤出、鼠标滚轮浏览、`↑` / `↓` 或点击选择、`Enter` 粘贴、`Esc` 关闭
- 粘贴时自动隐藏面板、还原原来的前台窗口再发送按键；终端类窗口改用 `Shift+Insert`
- 文本、图片、文件三类内容都能记录；图片转 PNG 落盘并显示缩略图
- 复制图片文件（非像素）时同样显示缩略图，粘贴回写为文件而不是路径文本
- 无边框面板 + DWM Mica 背景，四边可拖拽缩放，位置尺寸按显示器记忆
- 同一内容重复复制不新建条目，只把「最近使用时间」和次数往前推
- SQLite（WAL）存储，按保留天数自动清理

**计划中**

- 置顶区、条目编辑、类型过滤条（全部 / 文本 / 图片 / 文件 / 敏感）
- 敏感内容识别（进程黑名单 + 正则），只在内存中短暂存在
- 设置界面与 9 个可配置快捷键
- Velopack 打包与 GitHub Releases 自动更新

## 系统要求

- Windows 11（Mica 背景需要 22621+，低版本自动回退为不透明背景）
- .NET 9 SDK（自行构建时）

## 构建与运行

```powershell
dotnet build ClipStack.sln
dotnet run --project src/ClipStack.App
```

`--silent` 参数启动时不显示面板，供开机自启使用。

## 测试

```powershell
dotnet test ClipStack.sln
```

测试覆盖去重哈希、过期清理、PNG / DIB 编解码、DROPFILES 布局，以及真实剪贴板往返。

## 数据位置

全部数据都在 `%LOCALAPPDATA%\ClipStack\`：

| 路径 | 内容 |
|---|---|
| `clipstack.db` | SQLite 数据库（条目、来源、时间戳） |
| `settings.json` | 面板几何、设置 |
| `images\` | 图片条目，按内容哈希命名 |
| `logs\` | 每日日志，保留 7 天 |

日志只记哈希前缀与内容长度，不记剪贴板正文。

## 已知限制

- 只支持 Windows，只在 Windows 11 x64 上验证
- 回写图片只放 `PNG` 剪贴板格式，未同时放 `CF_DIB`，个别只认 DIB 的老程序可能粘不了图
- 权限提升的窗口、mstsc 远程桌面里只能复制，不能自动粘贴
- WSL 里只支持文本复制；图片复制需要经 Windows 侧工具
